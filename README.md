# Atividade-Sistema-de-Estacionamento-Inteligente-Park-Assist-
Este projeto simula a lógica de um sistema de estacionamento automático, onde o microcontrolador deve gerenciar a abertura/fechamento de uma cancela e, simultaneamente, um sistema de alerta de proximidade.
